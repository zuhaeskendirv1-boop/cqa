# Демо (5 минут)

0. Верх: провайдер/модель, счётчик вызовов и стоимости. Роль = admin.
1. **Диалоги** → импорт из API (ссылка) → «Оценить все неоценённые» → прогресс-бар.
2. Открыть звонок: плеер, ▶ у реплики, статистика звонка. Открыть чат с ⚠ автопроверками (запрос пароля).
3. Карточка: итог, секции, грубая ошибка. Клик по критерию → подсветка реплики-доказательства. Критерий «действие не найдено» → подсветка проверенного участка. N/A с причиной и перераспределённым весом.
4. «Показать трассу LLM» → промпт + сырой ответ модели (корректность процесса: анализ живой).
5. «Оспорить» → комментарий → **Апелляции** → изменить с причиной → новый итог → в карточке «AI → после проверки».
6. **Чек-лист**: поменять формулировку/вес/шкалу, добавить критерий, знания предметной области → сохранить (v+1) → переоценить диалог новой версией; старые оценки хранят снапшот.
7. **Калибровка**: разметка, MAE/смещение/худшие диалоги — так мы тюнили точность. Экспорт CSV для контрольного этапа.
