# Руководство по ручной разметке (ground truth)

Цель: 10–15 DEV-диалогов, оценённых командой так, как это сделали бы аудиторы Freedom Broker. По ним мы меряем MAE и калибруем модель. Это главная метрика отбора.

## Как размечать (вкладка «Калибровка», роль reviewer/admin)
1. Выберите разные диалоги: ~5 RU, ~3 KZ, ~3 EN, минимум 2 звонка, минимум 2 «плохих» (грубость, выдумки, запрос пароля).
2. Читайте только реплики `operator`. Бот и клиент — контекст.
3. По каждому критерию ставьте оценку **строго**: высший балл только если требование выполнено полностью и однозначно. Сомневаетесь между двумя — ставьте нижний.
4. N/A только по правилу N/A из чек-листа (например, приветствие — N/A, если поздоровался бот, а оператор подключился позже).
5. Разметьте в паре: двое оценивают независимо, расхождения обсуждаете и фиксируете правило в поле «описание» критерия или в «Знания предметной области».
6. Заметка — обязательна для спорных случаев (туда же пишите, что именно считать «частично»).

## После разметки
- Оцените эти диалоги AI → смотрите отчёт (MAE, смещение, худшие диалоги).
- Для каждого промаха: что модель не поняла? → уточните формулировку критерия или добавьте пример в `data/calibration.json`:
  ```json
  "resolution": [{"snippet": "operator: Скорее всего это за обслуживание.", "answer": 0, "why": "догадка без проверки, следующего шага нет"}]
  ```
- Переоцените: `python tools/compare_gt.py --reeval`. Цель: MAE < 5, |смещение| < 3, ≥80 % диалогов в пределах ±10.
